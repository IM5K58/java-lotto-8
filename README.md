# 기능 구현 목록

- [X] 1~45 사이의 숫자로 로또 번호를 생성
- [X] 1개의 로또 발행 시 6개의 숫자를 중복되지 않도록 뽑기
- [X] 당첨여부 확인
- [X] 수익률 계산
- [X] 당첨 번호 입력
- [X] 보너스 번호 한개를 입력
- [X] 입력받은 값에 대해 검증
- [] 예외 상황 발생시 [ERROR]로 시작하는 에러메세지를 출력한다.
- 예외 상황:
  - [X] 사용자의 입력 금액이 999 이하인 경우 (최소 한개의 로또는 사게 하기)
  - [X] 입력 금액이 1000으로 나누어 떨어지지 않는 경우
  - [] 입력한 당첨번호 중에 1~45 사이의 숫자가 아닌 값이 포함된 경우
  - [] 입력한 당첨번호에 중복된 값이 있는 경우
  - [X] 입력한 당첨번호가 6개가 안되는 경우
  - [] 입력한 보너스 번호가 1~45 사이의 숫자가 아닌 값인 경우
  - [] 입력한 보너스 번호와 당첨 번호들 사이에 중복된 값이 존재하는 경우
  - [] 입력한 번호가 숫자로만 이루어지지 않은 경우

- [] 입력한 가격에 맞는 횟수만큼 로또를 발행
- [] 수익률 출력 시 소수점 둘째자리에서 반올림
- [] 수익률 출력 시 '0' 3개 마다 ',' 붙이기
- [] 어떤 등 수에 몇번 당첨됐는 지 출력



# 유의 사항
- [] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현했는가?
- [] 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들었는가?
- [] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현하였는가?
- [] 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현하였는가?
- [] else 예약어를 쓰지 않았는가?
- [] Java Enum을 적용하여 프로그램을 구현하였는가?
- [] 구현한 기능에 대한 단위 테스트를 작성하였는가?
- [] 제공하는 라이브러리로 입출력/난수 생성을 처리하였는가?
- [] 제공된 Lotto 클래스를 사용하였는가?
- [] Lotto에 numbers 이외의 필드(인스턴스 변수)를 추가하지 않았는가?
- [] numbers의 접근 제어자인 private은 변경하지 않았는가?
